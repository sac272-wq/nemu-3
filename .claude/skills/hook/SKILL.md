# hook — 冒頭1〜2行づくり

## やること
タイムラインで指が止まる冒頭を5パターン作る。売り込み感は出さない。

## 使わんとき
- アフィ以外の投稿（threads-hook-creator を使う）
- 共通メモが無いとき（先に case を使うよう伝える。ユーザーが不要と言えば、その場で基本情報を聞く）

## 手順
1. 共通メモ `affiliate/notes/<商品名>.md` を読む（商品、ターゲット、悩み、実体験、case の型）
2. 次の切り口で1本ずつ作る
   - 悩みの代弁（「〇〇で困ってない？」）
   - 意外な事実・逆説
   - 自分の体験（Before→After）※実体験がある場合だけ
   - 数字や比較 ※根拠がある数字だけ
   - 失敗談・やらかし ※実体験がある場合だけ
3. 長さ：短くする。スマホで「続きを読む」で切れる前に言いたいことが伝わるようにする
   （何文字で切れるかは決めない。わからないため）
4. それぞれに「どんな人に刺さるか」を1行つける
5. おすすめを1本選んで理由を書く
6. ユーザーが選んだ冒頭を共通メモの「hook：決まった冒頭」に書く

## 守ること
- 実体験が無い切り口は作らない。無い体験を作らない
- 「絶対」「必ず」「誰でも」など、言い切って煽る言葉は使わない
- 効果・効能を約束しない（化粧品・健康食品・サプリは特に）
