# post — 本文づくり

## やること
hook で決めた冒頭から、リンクを踏みたくなる本文を作る。

## 使わんとき
- アフィ以外の投稿
- 冒頭が決まっていないとき（先に hook を使うよう伝える）

## 手順
1. 共通メモを読む（冒頭、商品、リンクの置き場所、PR表記の書き方、実体験）
2. 構成：冒頭 → 共感・悩み → 商品で変わったこと → 誘導
3. 文字数：1投稿500文字以内。Threadsの仕様が変わっていたら、ユーザーに今の上限を確認する
   長くなるときはスレッド（連投）に分ける
4. リンクの置き場所は共通メモのとおりにする。決まっていなければユーザーに聞く
5. PR表記は冒頭か、すぐ目に入る所に置く。ハッシュタグの中にまぎれさせない
6. 2パターン出して、違いを1行ずつ説明する
7. 共通メモの「post：本文の案」に書き、次に check を使うよう伝える

## 守ること
- PR表記は必ず入れる（ステマ規制）
- 使っていない商品を「使った」と書かない
- 価格・キャンペーンは、ユーザーが確認した情報だけ書く。わからなければ【要確認】と書いて空けておく
- 前の投稿と同じリンク・同じ文面を何度も使い回す案は出さない
