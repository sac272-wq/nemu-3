# 黒字家計簿

マイナスからでも「黒字転換」を目指すための、スマホ向け家計簿 Web アプリ（PWA）。

## できること
- **純資産（現金 − 借金）** と「黒字転換まであと何ヶ月か」の目安をホームに表示
- 収入・支出をワンタップのカテゴリで記録／編集／削除
- **レシート撮影で自動入力**（Tesseract.js による端末内 OCR。合計・日付・店名を推測 → 確認して保存）
- **固定費・定期収入**を登録しておくと、毎月「まとめて記録」できる
- **借金管理と返済プラン比較**：金利が高い順（アバランチ）と残高が少ない順（スノーボール）の完済月・利息総額を比較
- 支出のカテゴリ別内訳、直近6ヶ月の収支推移
- データは**端末のブラウザ内だけ**に保存（JSON で書き出し／読み込み可能）

## 注意点
- 返済シミュレーションは「年利 ÷ 12」の概算。実際の明細とはズレることがある
- 黒字転換の目安は直近の平均収支（返済を除く）から出しており、利息は含まない
- OCR の初回は日本語データ（数MB）を CDN からダウンロードするのでネット接続が必要。精度は撮影条件次第なので必ず確認して保存する
- ブラウザのデータを消すと記録も消えるので、定期的に「書き出し」でバックアップを

## 動かし方
静的ファイルだけなので、任意の静的サーバーで配信すれば動く。
```
npm start        # http://localhost:5173
npm test         # 計算ロジックのテスト
```
スマホでは HTTPS で公開（GitHub Pages / Vercel など）して「ホーム画面に追加」すればアプリのように使える。
